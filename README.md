# ChatBot 🤖📊
An intelligent data assistant for the AdventureWorks database that converts natural language questions into meaningful database insights via an interactive web interface.

## 🚀 Features
- Natural language querying on AdventureWorks database  
- AI-powered responses based on database data  
- Interactive and user-friendly web interface  
- Python-based backend API  
- Frontend built with HTML, CSS, and JavaScript  

---

## 🛠️ Tech Stack

### Backend
- Python  
- REST API  

### Frontend
- HTML  
- CSS  
- JavaScript  

### Database
- AdventureWorks

## 🎯 Use Case
This chatbot simplifies database interaction by allowing users to ask questions in natural language instead of writing complex SQL queries. It is especially useful for non-technical      users who want quick insights from the AdventureWorks database.
